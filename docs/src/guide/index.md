# 什么是 rw-vue-framework

rw-vue-framework 是一个基于 Element Plus 的 Vue3 管理后台框架，它使用面向对象的方式快速开发管理后台项目，它具有以下特点：
  -  **面向对象**
    面向对象开发，开发人员只需要关注业务逻辑，不需要关注页面布局
  -  **基于 Element Plus**
    绝大组件扩展自 Element Plus，组件和属性也完全兼容 Element Plus,会使用 Element Plus 的开发者可以无缝切换,本站没有特别说明的部分，均可以在[Element Plus](https://element-plus.org/#/zh-CN/)官网找到
  -  **统一样式**
     基于页面级组件开发，统一样式，统一布局，统一交互

     + **列表部分**
     删除样式、分页样式、表格样式、弹窗样式、树形样式、树形表格样式、树形表格样式
     + **表单部分**
     各基础控件、包括 tabs 组件、提交保存、临时保存、重置、校验、校验规则、校验提示、校验错误信息、校验错误信息位置

  -  **超强容错性**
    常规则校验自动加入，不需要开发人员更多关注，只需要关注业务逻辑
    + **列表部分**
    `addDate,addDateTime,addTime,addYear,addMobile,addIDCard`等，殚自动设置宽度以及样式效果
    + **表单部分**
    `RwInput`,设置`type`后，自动校验
    `struct`部分自动限定是否必填，字符长度，类型等
  -  **结构清晰**
    页面组件中结构清晰，快速向组件中添加业务逻辑
    + **列表部分**
    分为搜索区，列表区，功能区，操作区，分页区
    + **表单部分**
    分类表单区、按钮区

  - **快速开发**
    可以基于接口快速生成页面属性和多语言，通过工具还可以自动生成页面，此部分主要是从相应的表结构获取第一步初始数据后让用户快速生成参数

  - **集成常用功能**
    页面中集成常用功能，如：分页、表格、表单、弹窗、树形、树形表格、树形表格等
  - **页面布局完全由用户决定**
    绝大部分内容，均可以通过用户配置页面进行设置，如表单一行有多少列，label 显示位置等。
